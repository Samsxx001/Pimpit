# Pimpit 0.1.4

โปรแกรมแก้ข้อความที่พิมพ์สลับไทยเกษมณี / อังกฤษ US QWERTY สำหรับ Windows 10/11 x64 เขียนด้วย Rust ใช้ Win32 โดยตรง เป็นโปรแกรมอิสระ ไม่ใช้ซอร์สโค้ดของ RightLang เดิม

## เริ่มใช้

1. ปิด RightLang เดิมและ Rust รุ่นเก่า ให้ทำงานเพียงตัวเดียว
2. แตก ZIP ก่อน แล้วเปิด Pimpit.exe ในโฟลเดอร์ที่แตกแล้ว โปรแกรมอยู่ที่ไอคอนข้างนาฬิกา ไม่ต้องติดตั้ง
3. เลือกแป้นอังกฤษ พิมพ์ dki ใหม่แล้วหยุดประมาณ 0.12 วินาที จะเปลี่ยนเป็น การ เอง ไม่ต้องกด Space หรือปุ่มลัด
4. พิมพ์ l;ylfu จะขอแก้เป็น สวัสดี หรือ l;ylfu8iy[ เป็น สวัสดีครับ และขอเปลี่ยนแป้นเป็นไทยหากมีติดตั้ง หากคำกำกวมยังใช้ Shift+Backspace แปลงเองได้

| ปุ่ม | การทำงาน |
| --- | --- |
| Shift+Backspace หรือ Ctrl+Alt+Space | แปลงคำล่าสุด ก่อนหรือหลัง Space |
| ระหว่างพิมพ์ | แก้อัตโนมัติหลังคีย์ล่าสุดประมาณ 120 ms ไม่ต้องกด Space |
| Space | ตรวจแก้อีกครั้งเมื่อจบคำ |
| Ctrl+Alt+Z | ย้อนการแปลงล่าสุด ก่อนพิมพ์คำใหม่หรือย้ายเคอร์เซอร์ |
| Ctrl+Alt+P | พัก/เริ่มทำงาน |
| Ctrl+Alt+R | ลงทะเบียนรับคีย์และปุ่มลัดใหม่ โดยไม่ปิดโปรแกรม |

คลิกขวาไอคอนเพื่อพัก เปิด/ปิด Auto ซ่อมการรับคีย์ ดูสถานะ หรือออก ดับเบิลคลิกดูสถานะ

โปรแกรมเก็บคำที่พิมพ์หลังเปิดโปรแกรมในช่องปัจจุบัน ไม่อ่านข้อความเดิมหรือข้อความที่เลือกไว้ หลังคลิกย้ายเคอร์เซอร์ให้พิมพ์คำใหม่ก่อนใช้ปุ่มลัด

## พัก Auto เมื่อเล่นเกม (0.1.3)

เปิดใช้โดยปริยาย เมื่อหน้าต่างที่กำลังใช้งานเป็นเกม จะพักเฉพาะการแก้คำอัตโนมัติ พอสลับออกจากเกม เช่น Alt+Tab ไป ChatGPT จะกลับไปใช้ค่า Auto ที่คุณเลือกไว้ ถ้าคุณปิด Auto เอง ระบบจะไม่เปิดให้เมื่อออกจากเกม และล้างคำที่ค้างอยู่ทุกครั้งที่เข้า/ออกโหมดเกม

ตรวจจากชื่อ exe ที่รู้จัก (รวม Bomb Rush Cyberfunk, UNDERTALE, DELTARUNE), โฟลเดอร์ติดตั้ง Steam/Epic/Xbox/GOG, ชื่อ Unreal Shipping และหน้าต่างเต็มจอที่ Windows รายงานเป็น exclusive Direct3D รองรับเกมแบบหน้าต่างเมื่อชื่อหรือพาธอยู่ในรายการ ไม่ใช่ระบบระบุเกมทุกชนิดได้แน่นอน

เพิ่มชื่อเกมที่ยังตรวจไม่พบได้ใน pimpit.ini ข้าง exe แล้วเปิดใหม่:

    pause_auto_in_games=true
    game_exes=MyGame.exe,AnotherGame.exe

ไม่มีการสแกน process ทั้งเครื่องหรือฉีดโค้ดเข้าเกม ปุ่มลัดแปลงเองยังใช้ได้ตามเดิม Tooltip จะแสดง Auto suspended: game ระหว่างพัก ตรวจสถานะ game_active และ auto_effective ผ่านเครื่องมือสถานะได้ โดยไม่อ่านคำที่พิมพ์

## สิ่งที่เพิ่มใน 0.1.2

- ตรวจแก้ระหว่างพิมพ์ โดยรอคีย์ล่าสุด 120 ms และยกเลิกการแก้ที่รออยู่เมื่อมีคีย์ใหม่ เปลี่ยนโฟกัส คลิกเมาส์ หรือพักโปรแกรม
- รองรับคำตั้งแต่ 3 ตัวอักษร เช่น dki และคำไทยที่ติดกันซึ่งแบ่งได้เป็นคำในพจนานุกรม เช่น สวัสดีครับ
- ข้ามส่วนต้นของคำที่ยังอาจเป็นคำถูกในภาษาปัจจุบัน เช่น hel หรือ comp เพื่อลดการแปลงคำอังกฤษขณะยังพิมพ์ไม่จบ
- เพิ่มคำอังกฤษสั้นไว้ตรวจคำต้นทาง และรอให้ปล่อย Shift ก่อนแทนข้อความ
- หน้าสถานะสำหรับเครื่องมือแสดง Auto เปิดอยู่หรือไม่และจำนวนครั้งที่แก้อัตโนมัติ โดยไม่มีข้อความที่พิมพ์

## การแก้ไขจาก 0.1.1

- รับคีย์ผ่าน Raw Input และลงทะเบียน Shift+Backspace กับ RegisterHotKey โดยตรง ไม่มี low-level keyboard hook
- แยก Shift ซ้าย/ขวา และกันปุ่ม Backspace ของคำสั่งแปลงไม่ให้ล้างบัฟเฟอร์คำ
- รอชุดเหตุการณ์ Raw Input ของปุ่มลัดก่อนแปลง และยกเลิกเมื่อมีคีย์ใหม่หรือเปลี่ยนโฟกัส
- ตรวจ style รหัสผ่านเฉพาะ Edit/RichEdit ไม่ตีความ style ของหน้าต่างเบราว์เซอร์หรือ ChatGPT ผิด
- ใช้ keyboard layout ของช่องที่โฟกัสจริง
- แก้วงวนจากการลงทะเบียนอุปกรณ์ซ้ำใน WM_INPUT_DEVICE_CHANGE ซึ่งทำให้ CPU วนและคีย์/ตัวจับเวลาหยุดได้รับบริการ
- ลงทะเบียนรับคีย์ซ้ำทุก 30 วินาที เมื่อกลับจาก sleep หรือเปลี่ยนเซสชัน; การแจ้งเสียบ/ถอดอุปกรณ์จะล้างคำที่เก็บไว้โดยไม่ลงทะเบียนวนซ้ำ

## อัปเดตผ่าน GitHub (0.1.4)

คลิกขวาไอคอน > Check for updates / ตรวจสอบอัปเดต เมื่อมีรุ่นใหม่จะให้เลือกดาวน์โหลดและติดตั้ง โปรแกรมเปิดใหม่โดยเก็บ pimpit.ini เดิม มีสำรอง exe และย้อนกลับหากรุ่นใหม่เริ่มทำงานไม่สำเร็จ รุ่นที่ build ผ่าน GitHub จะตั้งแหล่งอัปเดตให้ผู้ใช้โดยอัตโนมัติ ดูขั้นตอนเจ้าของโปรแกรมใน GITHUB-TH.md รุ่นที่ยังไม่ได้ตั้ง repo จะแจ้งให้ตั้งค่าก่อน

## RAM และข้อมูล

ไม่มี WebView, Electron, GUI framework หรือโมเดล AI ใช้เธรดหน้าต่างกับ worker พจนานุกรมประมาณ 178,000 คำอยู่ในส่วนอ่านอย่างเดียวของ executable ค้นแบบ binary search คิวจำกัด 128 เหตุการณ์และคำจำกัด 96 ตัวอักษร การรอแก้อัตโนมัติใช้การรอคิวแบบมีเวลา ไม่วนตรวจทุกคีย์ตลอดเวลา

วัดรุ่นนี้หลังแปลงคำในเครื่องที่พัฒนาได้ working set ประมาณ 7.4 MB และ private bytes ประมาณ 1.4 MB ตัวเลขเปลี่ยนตาม Windows และการใช้งาน ไม่อ้างว่าเป็นค่าต่ำที่สุดทุกเครื่อง

การแก้คำทำงานออฟไลน์ ตัวอัปเดตติดต่อ GitHub เฉพาะเมื่อสั่งตรวจสอบอัปเดต ไม่ส่งข้อความที่พิมพ์หรือเขียนลงไฟล์ คำล่าสุดและ Undo อยู่ใน RAM สถานะ shared memory มีเฉพาะตัวเลข ข้าม password ของ Edit/RichEdit มาตรฐาน และ KeePass/KeePassXC/1Password/Bitwarden โดยปริยาย ช่องรหัสผ่านที่แอปหรือเว็บวาดเองอาจตรวจไม่ได้ ให้พักหรือยกเว้นทั้งแอปเมื่อต้องการ

## ตั้งค่าและขอบเขต

แก้ pimpit.ini ข้าง exe แล้วเปิดใหม่เพื่อโหลดค่าเริ่มต้น:

    auto_correct=true
    auto_delay_ms=120
    switch_layout=true
    pause_auto_in_games=true
    game_exes=
    exclude=game.exe,WindowsTerminal.exe,Code.exe

Auto ในเมนูมีผลระหว่างรอบที่เปิด ไม่ติดตั้ง autorun และไม่แก้ค่าของ RightLang เดิม

Auto ใช้กับข้อความอย่างน้อย 3 ตัวอักษร ต้นทางไม่ใช่คำที่รู้จักและปลายทางอยู่ในพจนานุกรม รองรับคำไทยติดกันหากแบ่งได้เป็นคำที่รู้จัก แต่ยังอาจข้ามชื่อเฉพาะ คำกำกวม หรือข้อความที่มีคำไม่รู้จัก ใช้ปุ่มลัดแปลงเองได้ ค่า auto_delay_ms ปรับได้ระหว่าง 60–2000 ms หลังเปิดใหม่ ไม่ใช่ตัวตรวจสะกดหรือแปลภาษา

การแทนข้อความใช้ Backspace และ Unicode ผ่าน SendInput แอปที่ลบสระ/วรรณยุกต์เป็นกลุ่ม เกม เทอร์มินัล และ editor บางตัวอาจต้องยกเว้นผ่าน exclude แอปที่เปิดแบบ administrator ต้องใช้ระดับสิทธิ์ที่สอดคล้องกัน Raw Input เน้นคีย์จากอุปกรณ์จริง การเปลี่ยน DOM หรือคีย์จาก macro อาจตรวจไม่ครบ

## สร้างและตรวจ

เครื่องนี้ใช้ .\build.ps1 -Test และ .\build.ps1 -NativeTest ได้ เครื่องอื่นติดตั้ง Rust stable-x86_64-pc-windows-gnu และ MinGW/w64devkit ตั้ง PIMPIT_MINGW_BIN เป็น bin ที่มี as.exe และใช้ cargo fetch --locked ครั้งแรกก่อน build แบบ offline

NativeTest ใช้ EDIT ของ Windows ที่ซ่อนอยู่และส่งข้อความตรง ไม่ส่งคีย์ไปยังแอปอื่น จึงไม่แทนการทดสอบแป้นจริง ผลที่ยืนยันแล้วอยู่ใน VALIDATION-TH.md

เครื่องมือ tools/Get-PimpitStatus.ps1 อ่านเฉพาะสถานะตัวเลข ไม่อ่านคำที่พิมพ์
